## Mission

Generate the four project-global impl infrastructure modules that the GSL pipeline produces from the full set of interfaces and implementations. These modules are currently not generated by the new codegen — they're only available as legacy resolved XML. Without them, `<require class="impl">` can't resolve, and the interface/implementation system has no runtime foundation.

### Module 1: `vscf_api.h` (api module)

- `api_tag` enum — one constant per interface (e.g., `vscf_api_tag_HASH`, `vscf_api_tag_CIPHER`, ..., `vscf_api_tag_END`)
- `api_t` base struct — the base type that all interface API structs inherit from (contains `api_tag` and `impl_tag` fields)
- Scope: public

### Module 2: `vscf_api_private.h` (api_private module)

- Internal details of the api infrastructure
- Scope: private

### Module 3: `vscf_impl.h/.c` (impl module)

- `impl_tag` enum — one constant per implementation (e.g., `vscf_impl_tag_SHA256`, `vscf_impl_tag_AES256_GCM`, ..., `vscf_impl_tag_END`)
- `impl_t` struct forward declaration
- Dispatch methods with generated bodies:
  - `vscf_impl_api(impl, api_tag)` — look up an API vtable from an impl
  - `vscf_impl_tag(impl)` — return the impl's tag
  - `vscf_impl_cleanup(impl)` — call cleanup through impl_info
  - `vscf_impl_delete(impl)` — call delete through impl_info
  - `vscf_impl_destroy(&impl)` — destroy + nullify
  - `vscf_impl_shallow_copy(impl)` — refcount increment
  - `vscf_impl_shallow_copy_const(impl)` — const variant
- Scope: public

### Module 4: `vscf_impl_private.h` (impl_private module)

- Callback typedefs: `vscf_impl_cleanup_fn`, `vscf_impl_delete_fn`, `vscf_impl_find_api_fn`
- `impl_info_t` struct — holds impl_tag, find_api callback, cleanup/delete callbacks
- `impl_t` struct definition — the actual struct with impl_info pointer and refcount
- Scope: private

These are **project-global** — they enumerate ALL interfaces/implementations in the project. The renderer must iterate `project_ir.interfaces` and `project_ir.implementations` to build the tag enums.

Reference resolved XML: `codegen/generated/foundation/c_module_vscf_api.xml`, `c_module_vscf_impl.xml`, `c_module_vscf_impl_private.xml`, `c_module_vscf_api_private.xml`.

Reference GSL: `codegen/c_module_impl.gsl` (409 lines), `codegen/c_module_impl_private.gsl` (242 lines).
